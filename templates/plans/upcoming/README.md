One file per horizon:

| File | Horizon | Bar for entry |
|------|---------|---------------|
| 🔥 [critical.md](critical.md) | **Critical** | Production risk or hard blocker |
| [now.md](now.md) | **Now** | In flight now |
| [next.md](next.md) | **Next** | Agreed, not started |
| [later.md](later.md) | **Later** | Backlog |

When something ships, move it to `changelog/(mmm-yy).md`.

## Rules

- An item lives in exactly one horizon. No duplicates.
- Critical may also appear in `now.md`, but `critical.md` is canonical.
- If critical grows beyond 4–5 items, escalate.
- Delete stale backlog.
